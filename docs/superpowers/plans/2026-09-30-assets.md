# Assets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Paragon a record of what is held — savings accounts and investments — alongside the flow it already tracks, so the owner can see a total, what each holding earns, and whether a movement went unrecorded.

**Architecture:** Two new tables (`accounts` for balances, `holdings` for investments) and four nullable columns on `transactions` naming where money came from and went. Balances move by transaction; holdings are revalued by hand. A reconciliation service compares recorded movements against the stated balance. One new page renders both groups under a single total; MCP tools cover entry.

**Tech Stack:** Bun, Elysia, Drizzle ORM, SQLite, React 19, Vite, Tailwind v4, TanStack Query, Eden Treaty, MCP SDK.

**Spec:** `docs/superpowers/specs/2026-09-30-assets-design.md`

## Global Constraints

- **Money is stored in minor units** as integers (`*_minor` columns). Never floats.
- **Rates are basis points** as integers (`rate_bp`): 4.25% is `425`.
- **Dates that mean a day are `"YYYY-MM-DD"` text**; instants are Unix seconds integers. Follow `commitments.activeFrom` for the former, `transactions.occurredOn` for the latter.
- **UI copy is Russian.** Two people read the screen.
- **Interest and coupons are income with `startsPeriod: false`.** Only a paycheque opens a pay period.
- **Revaluation is never a transaction.** It writes `holdings.value_minor` and `valued_at`.
- **Everyday cards are out of scope.** Do not add them, do not reconcile them.
- **Purchase lots are out of scope.** `invested_minor` against `value_minor` is the whole model.
- **Tests live in `apps/server/test/`**, never `tests/`. The helper at `test/helpers/db.ts` sets `DB_PATH` before importing `src/db`; import it first in every test file or the suite writes to the live database.
- **Run tests from `apps/server`** with `bun test`.

## Review Focus

Five conditions the spec implies that no single task's happy path exercises. Each has a test pinned to the task that owns the code.

1. **A transfer naming both an account and a holding on the same side** — must be rejected, not silently half-applied. Pinned to Task 3.
2. **A transfer naming the same account as source and destination** — must be rejected; it would reconcile as a no-op while looking like real movement. Pinned to Task 3.
3. **An account deleted while transactions still reference it** — must be refused (`ON DELETE RESTRICT`), because orphaned movements make reconciliation lie. Pinned to Task 2.
4. **Reconciliation when an account has no movements at all** — must report clean against the opening figure, not divide by zero or report a spurious gap. Pinned to Task 5.
5. **A holding revalued with no valuation yet (`value_minor` null)** — the total and the growth figure must not treat null as zero, which would report a 100% loss. Pinned to Task 4.

```ts
export const accounts = sqliteTable("accounts", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  name: text("name").notNull(),
  currency: text("currency").notNull().default("PLN"),
  // What the bank says today. Typed in by the owner, not derived: the application
  // sees only the movements it was told about, and the balance is the truth it is
  // checked against.
  balanceMinor: integer("balance_minor").notNull().default(0),
  // The balance on the day this account entered the application. Reconciliation counts
  // movements forward from here; without it there is nothing to count from.
  openingMinor: integer("opening_minor").notNull().default(0),
  openedOn: text("opened_on"),
  // Annual rate in basis points: 4.25% is 425. An integer, because money and rates
  // both lose to floating point.
  rateBp: integer("rate_bp"),
  // When a promotional rate lapses and the money should probably move.
  promoUntil: text("promo_until"),
  archivedAt: integer("archived_at"),
  createdAt: integer("created_at").notNull().default(sql`(unixepoch())`),
});

export const holdings = sqliteTable("holdings", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  name: text("name").notNull(),
  // "equity" or "bond".
  kind: text("kind").notNull(),
  // Sum of what was put in, moved by transfers rather than typed.
  investedMinor: integer("invested_minor").notNull().default(0),
  // What it is worth now. NULL until the first valuation: a holding bought today has
  // no price yet, and defaulting to zero would report it as a total loss.
  valueMinor: integer("value_minor"),
  valuedAt: text("valued_at"),
  rateBp: integer("rate_bp"),
  maturesOn: text("matures_on"),
  archivedAt: integer("archived_at"),
  createdAt: integer("created_at").notNull().default(sql`(unixepoch())`),
});
```

```ts
    onDelete: "restrict",
  }),
```

```ts
import { eq, isNull, asc } from "drizzle-orm";
import { db } from "../db";
import { accounts, holdings } from "../db/schema";

export type Account = {
  id: number;
  name: string;
  currency: string;
  balanceMinor: number;
  openingMinor: number;
  openedOn: string | null;
  rateBp: number | null;
  promoUntil: string | null;
};

export type Holding = {
  id: number;
  name: string;
  kind: "equity" | "bond";
  investedMinor: number;
  valueMinor: number | null;
  valuedAt: string | null;
  rateBp: number | null;
  maturesOn: string | null;
};

export type AccountInput = {
  name: string;
  balanceMinor: number;
  openingMinor: number;
  currency?: string;
  openedOn?: string | null;
  rateBp?: number | null;
  promoUntil?: string | null;
  archived?: boolean;
};

export type HoldingInput = {
  name: string;
  kind: "equity" | "bond";
  investedMinor: number;
  rateBp?: number | null;
  maturesOn?: string | null;
  archived?: boolean;
};

function toAccount(row: typeof accounts.$inferSelect): Account {
  return {
    id: row.id,
    name: row.name,
    currency: row.currency,
    balanceMinor: row.balanceMinor,
    openingMinor: row.openingMinor,
    openedOn: row.openedOn,
    rateBp: row.rateBp,
    promoUntil: row.promoUntil,
  };
}

/** Rows come back with `kind` widened to string; this narrows it once, centrally. */
function toHolding(row: typeof holdings.$inferSelect): Holding {
  return {
    id: row.id,
    name: row.name,
    kind: row.kind === "bond" ? "bond" : "equity",
    investedMinor: row.investedMinor,
    valueMinor: row.valueMinor,
    valuedAt: row.valuedAt,
    rateBp: row.rateBp,
    maturesOn: row.maturesOn,
  };
}

export function listAccounts(): Account[] {
  return db
    .select()
    .from(accounts)
    .where(isNull(accounts.archivedAt))
    .orderBy(asc(accounts.id))
    .all()
    .map(toAccount);
}

export function createAccount(input: AccountInput): Account {
  const row = db
    .insert(accounts)
    .values({
      name: input.name,
      currency: input.currency ?? "PLN",
      balanceMinor: input.balanceMinor,
      openingMinor: input.openingMinor,
      openedOn: input.openedOn ?? null,
      rateBp: input.rateBp ?? null,
      promoUntil: input.promoUntil ?? null,
    })
    .returning()
    .get();
  return toAccount(row);
}

export function updateAccount(id: number, input: Partial<AccountInput>): Account {
  const existing = db.select().from(accounts).where(eq(accounts.id, id)).get();
  // See the note on revalueHolding: the phrase drives the HTTP status.
  if (!existing) throw new Error(`Account not found: ${id}`);

  const row = db
    .update(accounts)
    .set({
      name: input.name ?? existing.name,
      balanceMinor: input.balanceMinor ?? existing.balanceMinor,
      openingMinor: input.openingMinor ?? existing.openingMinor,
      openedOn: input.openedOn !== undefined ? input.openedOn : existing.openedOn,
      rateBp: input.rateBp !== undefined ? input.rateBp : existing.rateBp,
      promoUntil: input.promoUntil !== undefined ? input.promoUntil : existing.promoUntil,
      archivedAt: input.archived ? Math.floor(Date.now() / 1000) : existing.archivedAt,
    })
    .where(eq(accounts.id, id))
    .returning()
    .get();
  return toAccount(row);
}

export function listHoldings(): Holding[] {
  return db
    .select()
    .from(holdings)
    .where(isNull(holdings.archivedAt))
    .orderBy(asc(holdings.id))
    .all()
    .map(toHolding);
}

export function createHolding(input: HoldingInput): Holding {
  const row = db
    .insert(holdings)
    .values({
      name: input.name,
      kind: input.kind,
      investedMinor: input.investedMinor,
      rateBp: input.rateBp ?? null,
      maturesOn: input.maturesOn ?? null,
    })
    .returning()
    .get();
  return toHolding(row);
}

/**
 * Sets what a holding is worth today.
 *
 * Deliberately not a transaction: the money did not move, only the price. Recording it
 * as income would inflate what the period reports as earned and corrupt every
 * comparison between months.
 */
export function revalueHolding(id: number, valueMinor: number, valuedAt: string): Holding {
  const existing = db.select().from(holdings).where(eq(holdings.id, id)).get();
  // "not found" is load-bearing: app.ts maps that phrase to a 404 and everything else
  // a service throws to a 422. A message without it would surface as a 500.
  if (!existing) throw new Error(`Holding not found: ${id}`);

  const row = db
    .update(holdings)
    .set({ valueMinor, valuedAt })
    .where(eq(holdings.id, id))
    .returning()
    .get();
  return toHolding(row);
}
```

- [ ] **Step 3: Add the invariant**

Append to `apps/server/src/services/invariants.ts`:

```ts
import { eq } from "drizzle-orm";
import { db } from "../db";
import { accounts, holdings } from "../db/schema";

export type AssetEndpoints = {
  fromAccountId?: number | null;
  toAccountId?: number | null;
  fromHoldingId?: number | null;
  toHoldingId?: number | null;
};

/**
 * Checks that a transaction names at most one source and one destination, and that
 * each exists.
 *
 * Money leaves one place and arrives in another. Naming an account and a holding on
 * the same side describes nothing real, and reconciliation would have to guess which
 * one to believe. A transfer to the account it came from is likewise incoherent: it
 * nets to zero, so it reconciles clean while looking on screen like money that moved.
 */
export function checkAssetEndpoints(input: AssetEndpoints): void {
  if (input.fromAccountId != null && input.fromHoldingId != null) {
    throw new Error("A transaction cannot name both an account and a holding as its source");
  }
  if (input.toAccountId != null && input.toHoldingId != null) {
    throw new Error("A transaction cannot name both an account and a holding as its destination");
  }
  if (
    input.fromAccountId != null &&
    input.toAccountId != null &&
    input.fromAccountId === input.toAccountId
  ) {
    throw new Error("A transfer cannot move money to the account it came from");
  }
  if (
    input.fromHoldingId != null &&
    input.toHoldingId != null &&
    input.fromHoldingId === input.toHoldingId
  ) {
    throw new Error("A transfer cannot move money to the holding it came from");
  }

  for (const id of [input.fromAccountId, input.toAccountId]) {
    if (id == null) continue;
    if (!db.select().from(accounts).where(eq(accounts.id, id)).get()) {
      throw new Error(`Unknown account: ${id}`);
    }
  }
  for (const id of [input.fromHoldingId, input.toHoldingId]) {
    if (id == null) continue;
    if (!db.select().from(holdings).where(eq(holdings.id, id)).get()) {
      throw new Error(`Unknown holding: ${id}`);
    }
  }
}
```

```ts
export type HoldingWithGrowth = Holding & {
  growthMinor: number | null;
  growthPercent: number | null;
};

export type AssetsSummary = {
  totalMinor: number;
  accounts: Account[];
  accountsTotalMinor: number;
  holdings: HoldingWithGrowth[];
  holdingsInvestedMinor: number;
  holdingsValueMinor: number;
  staleValuations: { id: number; name: string; valuedAt: string | null }[];
  expiringPromos: { id: number; name: string; promoUntil: string }[];
};

/** "YYYY-MM-DD" a given number of days from today, in local time. */
function dayOffset(days: number): string {
  const d = new Date();
  d.setDate(d.getDate() + days);
  return d.toISOString().slice(0, 10);
}

/**
 * What is held, and what it has done.
 *
 * A holding with no valuation counts at what was put into it. Treating an absent price
 * as zero would report a holding bought this morning as a total loss, and drag the
 * headline total down with it. Growth stays null in that case rather than claiming a
 * gain of zero, because "not yet known" and "unchanged" are different facts.
 */
export function assetsSummary(): AssetsSummary {
  const accountRows = listAccounts();
  const holdingRows = listHoldings();

  const accountsTotalMinor = accountRows.reduce((sum, a) => sum + a.balanceMinor, 0);

  const withGrowth: HoldingWithGrowth[] = holdingRows.map((h) => {
    if (h.valueMinor === null) {
      return { ...h, growthMinor: null, growthPercent: null };
    }
    const growthMinor = h.valueMinor - h.investedMinor;
    return {
      ...h,
      growthMinor,
      // A holding that cost nothing has no percentage to report; dividing would be
      // infinity, and rounding infinity produces a number that looks meaningful.
      growthPercent:
        h.investedMinor === 0 ? null : Math.round((growthMinor / h.investedMinor) * 100),
    };
  });

  const holdingsInvestedMinor = holdingRows.reduce((sum, h) => sum + h.investedMinor, 0);
  const holdingsValueMinor = holdingRows.reduce(
    (sum, h) => sum + (h.valueMinor ?? h.investedMinor),
    0,
  );

  const monthAgo = dayOffset(-30);
  const monthAhead = dayOffset(30);
  const today = dayOffset(0);

  return {
    totalMinor: accountsTotalMinor + holdingsValueMinor,
    accounts: accountRows,
    accountsTotalMinor,
    holdings: withGrowth,
    holdingsInvestedMinor,
    holdingsValueMinor,
    staleValuations: holdingRows
      .filter((h) => h.valuedAt !== null && h.valuedAt < monthAgo)
      .map((h) => ({ id: h.id, name: h.name, valuedAt: h.valuedAt })),
    expiringPromos: accountRows
      .filter((a) => a.promoUntil !== null && a.promoUntil >= today && a.promoUntil <= monthAhead)
      .map((a) => ({ id: a.id, name: a.name, promoUntil: a.promoUntil as string })),
  };
}
```

```ts
import { eq, gte, or, and } from "drizzle-orm";
import { db } from "../db";
import { transactions } from "../db/schema";
import { listAccounts } from "./assets";

export type Reconciliation = {
  accountId: number;
  name: string;
  expectedMinor: number;
  statedMinor: number;
  differenceMinor: number;
};

/** Unix seconds for midnight local time on a "YYYY-MM-DD" day. */
function dayStart(day: string): number {
  return Math.floor(new Date(`${day}T00:00:00`).getTime() / 1000);
}

/**
 * Compares what the application was told against what the bank says.
 *
 * The drift is the point. Savings movements are few, large, and recorded as they
 * happen, so a difference means one of them was missed — which is exactly the failure
 * this whole feature exists to catch. This works here only because everyday cards are
 * excluded: a card would disagree by lunchtime and the warning would be ignored
 * forever after.
 *
 * Accounts with no opening date are skipped rather than reported. There is nothing to
 * count from, so any figure produced would be arbitrary.
 */
export function reconcileAccounts(): Reconciliation[] {
  const gaps: Reconciliation[] = [];

  for (const account of listAccounts()) {
    if (account.openedOn === null) continue;
    const since = dayStart(account.openedOn);

    const rows = db
      .select()
      .from(transactions)
      .where(
        and(
          gte(transactions.occurredOn, since),
          or(
            eq(transactions.toAccountId, account.id),
            eq(transactions.fromAccountId, account.id),
          ),
        ),
      )
      .all();

    const movement = rows.reduce((sum, row) => {
      if (row.toAccountId === account.id) return sum + row.totalMinor;
      return sum - row.totalMinor;
    }, 0);

    const expectedMinor = account.openingMinor + movement;
    if (expectedMinor === account.balanceMinor) continue;

    gaps.push({
      accountId: account.id,
      name: account.name,
      expectedMinor,
      statedMinor: account.balanceMinor,
      differenceMinor: account.balanceMinor - expectedMinor,
    });
  }

  return gaps;
}
```

Note on signs: a negative-amount transfer is already how the owner records a returned deposit, so a row pointing *into* an account with a negative total correctly reduces it. No special case is needed.

```ts
import { reconcileAccounts } from "../../services/reconcile";

export const def = {
  name: "list_assets",
  config: {
    title: "List assets",
    description:
      "Returns every tracked account and holding with its id, balance or value, and rate. Call this before recording interest, a transfer to savings, or a revaluation, so that ids and names match what already exists. Everyday cards are deliberately not tracked.",
  },
};

export async function handler() {
  const summary = assetsSummary();
  const gaps = reconcileAccounts();

  if (summary.accounts.length === 0 && summary.holdings.length === 0) {
    return {
      content: [
        {
          type: "text" as const,
          text: "No accounts or holdings recorded yet.",
        },
      ],
    };
  }

  const lines: string[] = [`Total: ${formatMinor(summary.totalMinor)}`, ""];

  if (summary.accounts.length) {
    lines.push("Accounts:");
    for (const a of summary.accounts) {
      const rate = a.rateBp === null ? "" : ` at ${(a.rateBp / 100).toFixed(2)}%`;
      const promo = a.promoUntil ? ` (promo until ${a.promoUntil})` : "";
      lines.push(`  #${a.id} ${a.name}: ${formatMinor(a.balanceMinor)}${rate}${promo}`);
    }
    lines.push("");
  }

  if (summary.holdings.length) {
    lines.push("Holdings:");
    for (const h of summary.holdings) {
      const value = h.valueMinor === null ? "not valued yet" : formatMinor(h.valueMinor);
      const growth =
        h.growthMinor === null
          ? ""
          : ` (${h.growthMinor >= 0 ? "+" : ""}${formatMinor(h.growthMinor)})`;
      lines.push(
        `  #${h.id} ${h.name} [${h.kind}]: invested ${formatMinor(h.investedMinor)}, now ${value}${growth}`,
      );
    }
    lines.push("");
  }

  for (const gap of gaps) {
    lines.push(
      `Does not reconcile: ${gap.name} says ${formatMinor(gap.statedMinor)}, movements give ${formatMinor(gap.expectedMinor)} — a movement is probably missing.`,
    );
  }

  return { content: [{ type: "text" as const, text: lines.join("\n") }] };
}
```

`formatMinor` is re-exported from `apps/server/src/money.ts`, which forwards it from `@paragon/shared`. Import it from `../../money` as written above.
